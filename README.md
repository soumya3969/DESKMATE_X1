# DeskMate X1 - Smart Rechargeable Productivity Dashboard

Premium futuristic product landing page for the DeskMate X1 DIY smart desk gadget. Built with cinematic motion, glassmorphism UI, and a lightweight Three.js hero scene.

## Overview
- Futuristic dark aesthetic with glow effects and grid overlays
- Framer Motion powered interactions and scroll reveals
- React Three Fiber hero orb with subtle parallax
- Fully responsive layout for mobile, tablet, and desktop

## Tech Stack
- Vite
- React (JSX)
- Tailwind CSS
- Framer Motion
- Three.js + React Three Fiber + Drei
- Lucide React

## Getting Started
Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

## Build
Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
